# Лабораторная работа ТПМП 6 — iOS-приложения и локализация

Учебные iOS-примеры включают погоду, расчёт BMI/BMR, список достопримечательностей и перевод оценок. Некоторые задания содержат локализованные строки интерфейса.

## Технологии и структура

- отдельные проекты Xcode в `taskN/`;
- `docs/` — учебные заметки и протоколы;
- Swift, Objective-C, UIKit, SwiftUI, Xcode.

## Сборка и запуск

Откройте нужный `.xcodeproj` в Xcode на macOS и соберите приложение для симулятора или устройства. Единой кроссплатформенной команды сборки нет. Проверить Xcode-сборку в этой среде не удалось.
